# Collaboration panel

The reader groups co-author conversation into one sidebar panel with three tabs:

- **Chat** holds live document-wide conversation, with an unread indicator.
- **Comments** lists passage, figure, and point discussions in document order.
- **Highlights** lists marked passages, including marks with discussions.

A highlight with a body or replies appears in both Comments and Highlights.
Both views use the same annotation and reply IDs. Switching tabs preserves
chat and reply drafts. Clicking a mark opens its discussion; a highlight with
no discussion opens Highlights so a reader can add one.

The Point comment tool places a bubble at a text boundary without selecting
words. Clicking the bubble opens and expands its thread. Stored prefix and
suffix text locate the boundary after edits; missing context leaves the
comment unanchored rather than silently moving it to unrelated text.

Highlight creation offers four default colors and a custom color selector.
Colors are document data, persisted as validated six-digit hexadecimal RGB.
There is no strikethrough annotation tool.

The separate pencil **Changes** panel contains suggestion review and the
Suggest a change action. Show changes since… opens History with redlines
enabled. Suggestions and historical redlines retain their existing semantics;
this does not add a mode that tracks individual typing edits.

Old saved Chat and Comments panel preferences open Collaboration. Comment
and edit permissions still govern annotation creation and suggestion review.
Unconfirmed annotations retain their retry and discard controls.

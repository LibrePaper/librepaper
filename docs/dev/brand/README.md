# LibrePaper brand artwork

- Served artwork: [`web/public/assets/`](../../../web/public/assets/).
- Icon: edit `librepaper-icon.svg` there directly.
- Wordmark source: [`librepaper-logo-source.svg`](librepaper-logo-source.svg),
  with live Gotham HTF text.

To update the served wordmark:

1. Convert text to paths and export plain SVG from Inkscape.
2. Crop the view box with ten units of space around the drawing.
3. Commit [`web/public/assets/librepaper-logo.svg`](../../../web/public/assets/librepaper-logo.svg).

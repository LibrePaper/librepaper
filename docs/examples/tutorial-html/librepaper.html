Source and preview

This file is HTML, so LibrePaper displays its semantic elements directly. librepaper sync can keep a local project synchronized. The server synchronizes and stores the source; there is no separate compile step or rendering artifact.

A small scientific example

For a sample of size n, the standard error of a mean is SE=sn

A formula is a rule a machine can be made to follow, the point Ada Lovelace made when she described the Analytical Engine weaving algebraic patterns (Lovelace, 1843). HTML has no citation processor, so the project keeps its sources in references.bib and the document links to the formatted entry below.

HTML has no native include element. An iframe embeds the second project file as its own accessible document.

What HTML adds

HTML gives you explicit structure: headings, figures, captions, tables, and accessible alternative text. Try changing the figure caption and leave a comment on this paragraph.

Working with other clients

The browser editor reads and edits the page as stored. Use librepaper sync for local work, then share the saved HTML artifact. Readers need no compiler.

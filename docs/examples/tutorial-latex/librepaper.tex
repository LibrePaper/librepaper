\section{A small scientific example}

For a sample of size $n$, the standard error of a mean is
\begin{equation}
  SE = \frac{s}{\sqrt{n}}.
  \label{eq:standard-error}
\end{equation}

A formula is a rule a machine can be made to follow, the point Ada Lovelace
made when she described the Analytical Engine weaving algebraic patterns
\cite{lovelace1843}. Type \texttt{@} in the editor to cite another
entry from \texttt{references.bib}.

\section{What \LaTeX{} adds}

Packages make the document's capabilities explicit: \texttt{amsmath} provides
the equation environment, \texttt{booktabs} improves tables, and
\texttt{graphicx} loads the relative image asset. Try changing the estimate and
leave a comment on this paragraph.

\section{Working with other clients}

Choose Automatic, pdfLaTeX, XeLaTeX, or LuaLaTeX in Settings; availability depends on the pinned browser release. Use \texttt{librepaper sync} to edit the project with a local editor, and \texttt{librepaper publish} to publish from the terminal. Readers receive the stored PDF and do not need \LaTeX{} installed.

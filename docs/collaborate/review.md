## Preparing a response

The CLI exports a document project snapshot, not its comments. To prepare a
response, use the comments in the document and write the passages and replies
you need into your response document. The example below is illustrative; it is
not generated by a LibrePaper command.

## Response to reviewers

You can choose to address comments from a particular review round, but the
current CLI does not filter or export comments by checkpoint.


```markdown
## Reviewer: annegrandchamp

### 1. commenting, resolved in d1e0f42

> The confidence interval does not say that the parameter is inside it with 95% probability.

**Then:** "with 95% probability, the true value lies in the interval"

**Now:** no longer in the document.

**Vincent:** Fixed as suggested; see also the new footnote on coverage.
```

# Hybrid Biber validation

This fixture validates a browser hybrid runtime (WASM TeX plus CheerpX Biber)
using the corpus `biber-sorting` source. It has four cumulative edit trees:
`first`, `prose-edit`, `citation-addition`, and `title-edit`. Every tree is
compiled to convergence; the native oracle is generated by `native.mjs`.

```sh
node latex/benchmark/candidates/hybrid-validation/native.mjs
node latex/benchmark/candidates/hybrid-validation/self-test.mjs
node latex/benchmark/candidates/hybrid-validation/verify.mjs --candidate /path/to/output
```

The runtime adapter should write `91-sorting-schemes.pdf` and
`91-sorting-schemes.bbl` under one directory per phase. It may use either fresh
or incremental workspaces, but must expose the final converged files. The
verifier compares `.bbl` bytes to the matching phase's native `.bbl`, normalized
PDF text and page count, and exact Unicode markers. It also requires the newly
cited `glashow` entry and edited `companion` title to appear in extracted text.
Whitespace normalization is used only for PDF text because layout extraction
can wrap a title at a line boundary.

The fixture's phase trees are produced in memory from `treeOf`; no corpus files
are changed. Native generation can take a few minutes and should be run once
before timing the browser candidate, so its work is outside candidate timings.

Annotate anything

Markdown, HTML, Typst, LaTeX and Quarto all publish to the same reader, so a comment lands on the passage it is about whichever format wrote that passage.

Everyone at once

Several people annotate the same document simultaneously, with live updates. Two people editing the same sentence converge without either waiting for the other.

Publish from the CLI

librepaper publish sends a paper and the directory around it — the chapters, the figures, the .bib — from the project you already have.

Replying to a comment is writing the response to reviewers

Every comment records the checkpoint it was made on, so the export can quote the passage as the reviewer saw it and say what became of it since.

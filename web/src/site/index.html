Write

  • Live preview renders Markdown, HTML, Typst and LaTeX.
  • Computational notebooks include Quarto and Calepin.
  • Authoring includes templates, tools, and multi-file projects.
  • Bibliographies work with BibTeX and Zotero.
  • Track changes lets you accept or reject each edit.

Free

  • Everything is free. No feature is gated.
  • Open source covers the server, reader and renderers.
  • Public host at librepaper.org allows only 50 MB of storage per user and 30 uploads per hour.
  • Self-host needs one binary and a Postgres DB.
  • Export saves projects and comments as ordinary files.

People

  • Simultaneous editors get named carets and personal undo.
  • Annotate adds highlights and threaded comments.
  • Share with readers, commenters or editors.
  • Chat works with collaborators and AI agents.
  • History is granular and infinite.

Agents

  • Bring your own agent needs no new subscription.
  • Chat interface lets you ask for changes in the sidebar.
  • Pre-specified tasks: pick one with a passage selected
  • Permissions are reader, commenter, or editor.
  • Private: LibrePaper doesn't need your keys or tokens
  • MCP works with any commercial model or local weights.

# Unicode data notice

`emoji.json` is generated by `web/tools/fetch-emoji.mjs` from two sources:

- Emoji groups, order and fully-qualified sequences: Unicode emoji-test.txt, https://unicode.org/Public/emoji/latest/emoji-test.txt
- English names and keywords: Unicode CLDR annotations, https://github.com/unicode-org/cldr-json (files `cldr-json/cldr-annotations-full/annotations/en/annotations.json` and `cldr-json/cldr-annotations-derived-full/annotationsDerived/en/annotations.json`)

# French glossary

Register: "vous". Buttons and menu items use the infinitive ("Enregistrer"). Canadian French typography (OQLF): a non-breaking space before ":" only, none before "?", "!" or ";". Guillemets « » with non-breaking spaces inside.

Menu titles: File = Fichier, Edit = Édition, Insert = Insertion, View = Affichage.

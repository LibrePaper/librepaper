\section{A missing file}

The next line asks for a file this directory does not have, which is the
error a reader gets when an \verb|\input| outlives the file it named. It
comes last because \TeX{} stops dead on it: an input it cannot find is an
emergency stop, so anything after it would never be reported, and a fixture
of four errors has to reach all four.

\input{chapters/missing}

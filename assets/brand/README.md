# LibrePaper brand artwork

These are the editable source files for LibrePaper's icon and wordmark.
The web-ready derivatives live in `web/public/assets/`, where Vite copies
them into the deployed application.

The icon is copied without modification. The logo source keeps its word as
editable Gotham HTF text; export it with Inkscape's text-to-path and plain-SVG
options, then crop the view box with ten units of space around the drawing.
Commit the resulting outlined file as `web/public/assets/librepaper-logo.svg`.
